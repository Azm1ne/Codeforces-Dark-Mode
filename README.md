# Codeforces Dark Mode (with the help of ChatGPT)

A simple, lightweight browser extension that applies a fully custom dark theme to the entire Codeforces website.  
No scripts, no performance hit — just a clean CSS override via content scripts.
The code was completely generated by ChatGPT.


## ✨ Features

- Full-site dark mode for Codeforces  
- Consistent dark backgrounds, borders, and typography  
- Styled tables, problem statements, blogs, comments, and menus  
- Preserves Codeforces user-color ranks  
- No JavaScript — CSS only  
- Works automatically on all `https://codeforces.com/*` pages
